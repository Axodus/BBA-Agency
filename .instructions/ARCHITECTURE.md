# BBA-Agency Architecture

Status: planning/prototype only

BBA-Agency should remain separated from protocol execution.

## Responsibility

- brand system planning;
- agency communication models;
- campaign and content concepts;
- ecosystem visibility strategy;
- non-production presentation assets.

## Non-Responsibilities

- Governance authority;
- treasury authority;
- product execution;
- wallet execution;
- settlement;
- trading;
- swaps;
- production service delivery;
- legal or compliance approval.

## Integration Boundary

BBA-Agency may reference other Axodus nuclei only as documented ecosystem concepts. It must not create source-of-truth claims about product status, production readiness, partnerships, audits, token economics, or financial outcomes.
