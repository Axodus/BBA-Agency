# BBA-Agency Instructions

Current Phase: `PLANNING` / `PROTOTYPE`  
Production Status: `NOT PRODUCTION READY`  
Execution Status: `EXECUTION_DISABLED`

BBA-Agency is the brand, communications, campaign, and visibility planning layer for Axodus.

This workspace must use conservative language and must not imply production launches, financial outcomes, partnerships, audits, or operational delivery unless separately validated and approved.

## Allowed Work

- brand planning;
- communication strategy;
- campaign concept docs;
- prototype copy;
- non-production design direction;
- documentation hygiene.

## Forbidden Work

- production campaign claims;
- fake partnerships;
- fake audit claims;
- financial guarantees;
- unrealistic APY/yield claims;
- production deployment claims;
- wallet, treasury, trading, DEX, Marketplace, Lottery, Mining, or settlement execution.
