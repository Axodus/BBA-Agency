# Historical Plans

This collection preserves planning records and status snapshots that predate
the active BBA Agency workspace established on September 3, 2026.

The documents describe the archived AXODUS campaign-agent framework, including
legacy `src/` and `axodus/` layouts, MongoDB/Chroma memory infrastructure,
campaign-oriented agents, and `npm` commands. These are retrieval context only;
they are not current implementation instructions, operational status, or proof
of active integrations.

For current work, begin with the
[BBA Agency Operational Documentation Index](../OPERATIONAL_INDEX.md).

The related source snapshot is preserved in the branch
`archive/dev-legacy-demo-src-2026-09-03`.
