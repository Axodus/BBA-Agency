# Local Architecture Decision Records

Local ADRs record durable implementation choices for `core/`. They do not
override the certified BBA Platform ADRs in the private Documentation corpus.

## Status taxonomy

Allowed statuses are `PROPOSED`, `ACCEPTED`, `DEFERRED`, `SUPERSEDED`, and `REJECTED`.
An ADR may be `ACCEPTED` for implementation while remaining subject to the
upstream documentation review process.
